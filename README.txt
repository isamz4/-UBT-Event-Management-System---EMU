UBT Event Management System V5 — Functional Build
Open index.html in a modern browser.

What works:
- Arabic/English + RTL/LTR
- Interactive dashboard filters and clickable KPIs
- Event create/edit/delete and readiness
- Calendar linked to event records
- Event request create/edit + convert approved request to event
- Tasks create/edit/status + approvals update
- Sponsors & Partners database + follow-up history + CSV export
- Reports generated from live browser data
- Activity log
- Mobile responsive navigation
- Browser persistence via localStorage

Prototype note:
Authentication, multi-user database, Microsoft SSO, server file uploads, and true server-side permissions require a production backend.
