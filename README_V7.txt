UBT EMU V7 — Source-faithful event naming

Event titles from the uploaded Unified Calendar are preserved as written in the source.
- English-only titles stay English even when the UI is Arabic.
- Arabic-only titles stay Arabic even when the UI is English.
- Mixed/bilingual source titles remain mixed/bilingual.
- The system UI itself still switches Arabic/English.
- Event forms now label the second-language title as optional and only for officially supplied translations.

All V6 visual refinements and V5 functional interactions remain included.
